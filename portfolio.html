Stack Técnico 02 / 04
Tecnología sin fricción

La decisión de construir sin frameworks fue intencional: máximo rendimiento, cero tiempo de build, deploy instantáneo en cualquier hosting estático.

🌐
HTML5 Semántico
Shell del SPA en un único index.html. Estructura accesible con roles ARIA y skip-links.
🎨
CSS Variables + Custom Design System
Paleta "Botanical Warmth" (verde bosque + terracota) definida en :root. Sin frameworks CSS.
⚡
JavaScript Vanilla ES6+
SPA completa con hash routing, renderizado dinámico, manejo de estado y persistencia en localStorage.
💾
localStorage
Carrito y pedidos persistidos bajo la clave latinoamericana_orders. Sin backend, sin cookies.
✒️
Google Fonts
Fraunces (display serif) + Plus Jakarta Sans (texto). Tipografía editorial con alta legibilidad.
📦
Font Awesome 6.4
Íconos vía CDN para carrito, navegación, redes sociales y acciones del usuario.
¿Por qué no React, Vue o Next.js?
  • Carga instantánea — no hay bundle JS de 100–400 KB que parsear antes del primer render
  • Deploy con un simple git push a GitHub Pages, Netlify o cualquier CDN
  • Sin dependencias que actualizar, sin vulnerabilidades en node_modules
  • El cliente objetivo no necesita SSR, autenticación compleja ni estado distribuido

Funcionalidades & Catálogo 03 / 04
Funcionalidades principales
🛒 Carrito de compras
Sidebar animado con añadir/remover productos, contador en tiempo real y total acumulado. Persiste al recargar la página.
💬 Checkout por WhatsApp
El carrito genera un mensaje estructurado con nombre, cantidad y precio de cada ítem, listo para enviar al número de la empresa.
🔍 Búsqueda en tiempo real
Header expandible con campo de búsqueda que filtra el catálogo instantáneamente mientras el usuario escribe.
🗂️ Filtros y ordenamiento
Filtro por categoría, búsqueda por texto y ordenamiento por precio (ascendente / descendente) con UI responsiva.
📸 Carrusel de banners
Carrusel hero con slides para Inicio, Ropa Usada y Packs & Combos. Navegación con botones e indicadores.
🧩 Packs & Combos
Categoría especial de kits con descuento aplicado. La card detalla cada producto incluido con badge de ahorro.
📄 Hash Routing (SPA)
Navegación sin recarga entre 8 vistas: Inicio, Catálogo, Ofertas, Ropa Usada, Detalle, Contacto, Admin y páginas legales.
🔧 Panel Admin
Vista de pedidos guardados en localStorage. Permite revisar el historial de órdenes sin backend ni autenticación.
